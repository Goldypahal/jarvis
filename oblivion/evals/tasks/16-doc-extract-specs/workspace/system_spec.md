# Oblivion System Specifications

## Minimum Requirements
- Operating System: Windows 11 or Linux Ubuntu 22.04+
- Architecture: x86_64
- Memory: 16 GB minimum recommended RAM (8 GB strictly required minimum)
- Storage: 20 GB free disk space

## Networking
The service listens on the following TCP ports:
- 7878 (Web UI)
- 8080 (Bridge)
- 9090 (Telemetry)
